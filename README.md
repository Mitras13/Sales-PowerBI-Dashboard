![SQL Server](https://img.shields.io/badge/SQL%20Server-data%20source-CC2927)

داشبورد مدیریتی فارسی (RTL) برای پایش **فروش، وصول، تارگت، و عملکرد تیم فروش**. ساخته‌شده با **Power BI Desktop**، داده از **SQL Server** و فایل‌های Excel، با کوئری‌های **Power Query (M)** و مژرهای **DAX**. این ریپو شامل کد Power Query، مژرهای DAX، تم گزارش و مستندات است. **داده‌های واقعی و فایل `.pbix` عمداً در این ریپو نیستند** (شامل اطلاعات مشتریان و مبالغ واقعی شرکت است).

## صفحات گزارش
| صفحه | هدف |
|---|---|
| خلاصه مدیریتی | نمای کلی: کارت‌های کلیدی، روند ماهانه، سهم سرپرستان و استان‌ها |
| فروش محصولات | تحلیل محصولات (سطح ۱/۲/۳)، روند ماهانه و سهم استان‌ها |
| عملکرد تیم فروش | بازدهی کارشناسان (پراکندگی ضریب وصولی)، وضعیت فعال/غیرفعال، مدیران و سرپرستان |
| ضریب وصولی | جدول ماهانه‌ی ضریب وصولی هر کارشناس |

## ساختار ریپو
```
powerquery/   کوئری‌های Power Query (هر فایل = یک جدول)
theme/        تم گزارش (Navy)
docs/         مستندات فرمول‌ها و تغییرات
screenshots/  تصاویر خروجی گزارش (بدون داده‌ی حساس)
```

## فرمول‌های کلیدی
- **ضریب وصولی** = مبلغ وصولی کارتابلی ÷ تعداد پاسخ داد کارتابلی (واحد: هزار تومان به‌ازای هر تماس پاسخ‌داده)
- **تارگت وصول** از جدول تارگت ماهانه (میلیون تومان) خوانده می‌شه.
- **درصد تحقق هدف** = وصول کل ÷ تارگت ماه.
- **رشد ماهانه** نسبت به ماه قبل، با تقویم شمسی و کلید `سال*100+ایندکس ماه`.

جزئیات DAX در `docs/measures.md` هست.

## منبع داده
- SQL Server محلی (دیتابیس `Mitra_sarkhosh`)
- فایل‌های Excel تارگت (شیت یکپارچه)
- گزارش‌های روزانه‌ی فاکتور، وصول و تماس که با یک دانلودر جدا بروز می‌شن (این ریپو شامل دانلودر نیست).

## نحوه‌ی استفاده
1. ریپو رو کلون کنید.
2. فایل‌های `powerquery/*.m` رو در Power BI Desktop به‌ترتیب شماره‌شون وارد کنید (Advanced Editor).
3. ارتباط با داده‌ی خودتون رو تنظیم کنید (مسیر فایل‌ها و سرور).
4. تم `theme/dashboard_theme_navy.json` رو از `View > Themes > Browse` اعمال کنید.
